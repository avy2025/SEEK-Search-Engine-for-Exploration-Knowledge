# Search Engines

A search engine indexes a collection and retrieves documents that match a
user's query. A lexical ranker such as BM25 scores documents using query-term
frequency and document length. It is effective for exact keywords, names, and
technical identifiers.

Hybrid search combines lexical scores with semantic similarity from text
embeddings. Candidate generation retrieves a manageable set of documents, and
ranking can combine signals before snippets and sources are returned. Clear
empty, loading, and error states help users understand search results.
