# Natural Language Processing

Natural language processing (NLP) applies computational methods to human
language. Common tasks include tokenization, text classification, named-entity
recognition, translation, summarization, and question answering. A tokenizer
turns text into units that a model or retrieval system can process.

Search systems often normalize case and punctuation, remove common stop words,
and preserve important technical terms. Modern NLP models can create embeddings
that represent meaning, while lexical methods such as BM25 remain useful for
exact names, identifiers, and uncommon words.
