# Information Retrieval

Information retrieval finds useful documents in a collection in response to a
query. A search system can normalize text, build an inverted index, retrieve
candidates, rank them, and present snippets with links to their sources.
Relevance depends on both the query and the user's information need.

Evaluation uses representative queries and relevance judgments. Precision
measures how many returned documents are relevant, while recall measures how
many relevant documents were found. Ranking metrics such as mean reciprocal
rank and normalized discounted cumulative gain account for result order.
