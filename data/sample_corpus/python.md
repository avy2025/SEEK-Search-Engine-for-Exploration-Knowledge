# Python

Python is a general-purpose programming language used for web services, data
analysis, automation, and machine learning. Its readable syntax, standard
library, and package ecosystem make it suitable for prototypes and production
applications. FastAPI uses Python type hints to define HTTP APIs and validate
request data.

Use a virtual environment to isolate project dependencies. Automated tests
protect behavior as code changes, and formatters and type checkers make
maintenance easier. Python programs can expose asynchronous endpoints, read
configuration from environment variables, and connect to databases through
well-supported libraries.
