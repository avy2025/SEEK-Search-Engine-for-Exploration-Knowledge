# Machine Learning

Machine learning uses examples to fit a model that makes predictions on new
data. Supervised learning learns from labeled examples; unsupervised learning
looks for structure without labels. A training set fits the model, while
validation and test sets help estimate how it generalizes.

Data quality, leakage, and evaluation design can matter as much as model choice.
Embeddings are learned numeric representations that place related text or
images near one another in vector space. They support semantic search, clustering,
and retrieval-augmented generation.
